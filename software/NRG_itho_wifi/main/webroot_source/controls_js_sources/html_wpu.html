Fault settings

For every fault the heat pump stores how it reacts to it: how long the fault must be present, when and how often it retries, how it is reported and which functions are blocked while the fault is active. This page only reads these settings; nothing is changed on the heat pump.

What the columns mean
  • Priority: decides which fault is shown when several faults are active at the same time.
  • Fault time: how long the fault must be present before the heat pump acts on it (raw value as stored in the heat pump, most likely seconds).
  • Retry time: how long the heat pump waits before it tries again (same unit).
  • Retries: how many retries before the heat pump goes into fault.
  • Report: how the fault is reported (on the thermostat, with or without the fault relay, or unlimited retries).
  • Blocked functions: what is switched off while the fault is active (✓ = blocked).
